# أوه يامال 🐚

لعبة غوص اللؤلؤ لـ ٦ لاعبين أونلاين.

- **الشاشة الرئيسية** (تلفزيون أو لابتوب): افتح رابط الموقع `/`، وتطلع لك الباركود وكود الغرفة.
- **اللاعبين**: يمسحون الباركود، أو يفتحون `/play` ويكتبون الكود، ويكتبون أسماءهم ويضغطون ⚓.
- إذا كان اللاعبون أقل من ٦، الكمبيوتر يسوق السفن الباقية.
- تقدر تلعب بنفسك من الشاشة الرئيسية: اكتب اسمك تحت واضغط ⚓.

## التشغيل محلياً
```
node server.js   # http://localhost:3000
```
بدون أي مكتبات خارجية، يحتاج Node 18 أو أحدث فقط.
